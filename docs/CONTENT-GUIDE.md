# دليل المحتوى — كيف تُضاف صفحة أو تُعدَّل نصّاً

> لمن يريد التعديل بلا كسر شيء.

---

## القاعدة الذهبية

| ما تريد تعديله | أين |
|---|---|
| **نصّ** خاصّ بمدينة/خدمة | `src/lib/localContent.tsx` |
| **صور** خاصّة بمدينة/خدمة | `src/lib/localImagery.ts` |
| **بنية** الصفحة (تمسّ الـ ٢٤ كلها) | `src/components/LocalServicePage.tsx` |
| مدينة أو خدمة جديدة | `src/lib/localPages.ts` |

> ⚠️ **لا تُخصّص المكوّن بشروط `if (city === "jeddah")`.** التمايز يأتي من **طبعة البيانات**. المكوّن يوفّر الجودة الموحّدة، والبيانات توفّر الهوية المختلفة. من خصّص المكوّن أفسد المعمار وجعل كل تعديل لاحق خطراً على ٢٤ صفحة.

## تعديل نصّ صفحة موجودة

1. افتح `src/lib/localContent.tsx`
2. اعثر على مفتاح التركيبة (مثل `sababin-qahwa-jeddah`)
3. عدّل الحقل

**ثم — إلزامي:**
```bash
npm run build
python3 research/scripts/shoot_mobile.py sababin-qahwa-jeddah L
# واقرأ الشرائح بعينك
```

**تحقّق من:**
- [ ] `price = false` — لم يدخل رقم سعر
- [ ] `screens` لم يزد كثيراً — الطول عدوّ
- [ ] النصّ يُقرأ فوق الصورة

## إضافة مدينة

```ts
// src/lib/localPages.ts
export const CITIES = {
  // …
  taif: { slug: "taif", nameAr: "الطائف", /* … */ },
};
```

**الأثر:** ٣ صفحات جديدة تلقائياً (خدمة واحدة لكل).

**ثم — إلزامي:** أضِف محتوىً **أصيلاً** لكل تركيبة جديدة في `localContent.tsx` و`localImagery.ts`.

> ⚠️ **مدينة بلا محتوى خاصّ = ٣ صفحات متشابهة = محتوى مكرّر يضرّ الـ SEO.** إن لم يتوفّر محتوى حقيقي، **لا تُضَف المدينة.**

---

## إضافة خدمة (المطلب ٩)

```ts
// src/lib/localPages.ts
export const SERVICES = {
  // …
  "new-service": { slug: "new-service", nameAr: "…", /* … */ },
};
```

**الأثر:** **٨ صفحات جديدة دفعةً واحدة** — أخطر تعديل في المشروع.

**الشرط الصريح:** لكل تركيبة من الثماني:
- [ ] عنوان مختلف حقيقي
- [ ] نصّ مختلف — لا استبدال اسم المدينة فقط
- [ ] أسئلة شائعة مختلفة
- [ ] صور مناسبة للخدمة
- [ ] **لا سعر**

**ثم:** صوّر **٣ مدن مختلفة** على الأقلّ وتأكّد أن العناوين والأغلفة مختلفة فعلاً.

## إضافة صورة

**١) الاسم بكلمات مفتاحية:**
```
[الخدمة]-[المدينة]-[المشهد]-keif-aldiafa.webp
مثال: qahwajiyeen-taif-wedding-hall-keif-aldiafa.webp
```

**٢) أضِف مُدخَلاً في `JOBS` داخل `research/scripts/watermark_engrave.py`** مع نصّ بديل **عربي وصفي**:
> «قهوجيين في قاعة أعراس بالطائف — كيف الضيافة»

نصّ بديل محشو بالكلمات يضرّ ولا ينفع.

**٣) شغّل:**
```bash
python3 research/scripts/watermark_engrave.py
rm -rf .next/cache/images && npm run build
```

**٤) اربطها** في `src/lib/localImagery.ts`

**٥) تحقّق:** كبّر الزاوية وانظر إلى العلامة المائية — لا تفترض النجاح.

## إضافة صفحة مستقلّة

اتبع نمط `src/app/social/`:

```
src/app/<name>/
├── page.tsx        ← metadata + JSON-LD + استيراد العميل
└── <Name>Client.tsx ← "use client" + العرض
```

**ثم:**
1. **سجّلها في `src/app/sitemap.ts`** — وإلّا لن تُكتشف
2. اربطها من `Footer.tsx` أو `Navbar.tsx`
3. **احسب الحشو العلوي بحسب ما تبدأ به:**
   - تبدأ بغلاف طويل → `pt` صغير يكفي
   - **تبدأ بنصّ → `pt-28 sm:pt-36`** وإلّا التصق بشريط الشعار (~٩٦px)

**استعمل الأصناف الموجودة:**
```
lx-eyebrow · ls-h1 · lx-lead · lx-h2 · lx-btn lx-btn--gold · lx-btn lx-btn--ghost
lx-lift · lx-medal · lx-orn · ls-band (شريط النداء الأخير)
```

> ⚠️ **`grep` قبل أي صنف جديد.** اختراع صنف موازٍ يُنتج مظهرين متشابهين لا يتطابقان.

## نبرة الكتابة

**نعم:**
- خطاب مباشر للعميل: «مناسبتك» لا «مناسبات العملاء»
- وصف ملموس: «كاونتر القهوة، الطاقم بزيّه، التوزيعات في يد الضيف»
- جُمل قصيرة — الزائر يتصفّح لا يقرأ
- **قُل ماذا يجد العميل**، لا اسم الشيء فقط

**لا:**
- ❌ أي سعر أو باقة أو «يبدأ من»
- ❌ مبالغة فارغة: «الأفضل في الشرق الأوسط»
- ❌ فقرات طويلة
- ❌ حشو كلمات مفتاحية
