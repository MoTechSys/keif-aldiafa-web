# الباركود — التوثيق التقني

**الأداة:** [`research/scripts/qr_generate.py`](../research/scripts/qr_generate.py)
**المُخرَج:** `public/images/brand/qr-keif-aldiafa.png` — 984×984 · ٧٠ ك.ب
**الهدف:** `https://keifaldiafa.com/social`

---

## القاعدة الحاكمة

> ## الباركود لا يُحكم عليه بالعين.

باركود ميت يبدو **سليماً وجميلاً تماماً** على الشاشة. والعميل الذي يصوّره ولا يُفتح له شيء **لا يشتكي ولا يتصل** — يذهب بصمت. لا رسالة خطأ، ولا أثر في أي سجلّ.

**فكل تغيير يمسّ الباركود يُتبَع بفكٍّ برمجي.** بلا استثناء.

---

## القيود الأربعة غير القابلة للتفاوض

| # | القيد | السبب |
|---|---|---|
| ١ | تصحيح خطأ **`H`** (أعلى مستوى) | ليصمد مع شعارٍ يحجب جزءاً من البيانات |
| ٢ | الشعار **≤ ١٩٪** من المساحة | فوقها يتجاوز قدرة `H` على التعويض |
| ٣ | مربّعات التحديد **مصمتة غير مشوّهة** | الماسح يجدها أولاً؛ تزيينها = فشل الكشف |
| ٤ | **قطبية موجبة** — حبر داكن على ورق فاتح | قلبُها يفشل مع بعض ماسحات أندرويد |

**القيد ٤ يشرح تصميماً يبدو مخالفاً للصفحة:** بطاقة `.lx-qr` **كريمية والصفحة بنّية داكنة**. هذا مقصود، لا سهو.

## أين تدخل الفخامة؟ حول الرمز لا فوقه

**مسموح — حول الرمز:**
- حدّ ذهبي `rgba(197,160,89,0.55)`
- ظلّ حلقيّ `box-shadow: 0 0 0 6px …`
- ارتفاع عند اللمس `translateY(-5px)`
- زوايا مستديرة للبطاقة

**ممنوع — فوق الرمز:**
- ❌ تدرّج لوني
- ❌ حجاب أو طبقة شفافة
- ❌ لمعة أو انعكاس
- ❌ ظلّ داخلي

كلها تقتل القراءة.

**والمسموح داخل الرمز** (لا يمسّ البيانات): وحدات دائرية بدل مربّعة، نوى ذهبية داخل مربّعات التحديد، شعار في القلب بحدّ ذهبي.

**لماذا `OUT` داخل `/images/`؟**

العلاج الصحيح: **نقل الملف** — لا توسيع السياسة لأجل ملف واحد.

## ⚠️ المصيدة الكبرى: مُحسِّن الصور يقتل الباركود

بعد إصلاح المسار أعاد المُحسِّن **200**. ولم يكن ذلك كافياً. جلبتُ **مُخرَجه الفعلي** وفكَكتُه:

```
served (384, 384) WEBP
decode -> FAIL
```

**السبب:** التحويل إلى WebP بضغط ضائع عند `q=75`. ووحدات الباركود **حدود حادّة بين أسود وأبيض** — والضغط الضائع يُلطّف الحدود فتنزل تحت حدّ القراءة. والتصغير إلى 384px يُضاعف الأثر.

**العلاج:**

```tsx
<Image
  src="/images/brand/qr-keif-aldiafa.png"
  width={984} height={984}
  unoptimized              /* شرط صحّة لا مقايضة أداء */
  sizes="(max-width:640px) 224px, 288px"
  className="w-[224px] h-[224px] sm:w-[288px] sm:h-[288px]"
/>
```

`unoptimized` هنا **ليس تنازلاً عن الأداء**: الملف ٧٠ ك.ب فقط، ولا مكسب في الحجم يوازي **علامةً لا تُمسح**.

**التحقّق بعد الإصلاح:**
```
200 image/png · served (984,984) PNG
decode -> ['https://keifaldiafa.com/social']
```

## اختبار المقاسات — لماذا ٢٢٤px؟

فُكَّ الباركود بـ `pyzbar` عند كل مقاس:

| المقاس | النتيجة |
|---|---|
| 984px | ✅ |
| 512px | ✅ |
| 320px | ✅ |
| 240px | ✅ |
| **180px** | ✅ **الحدّ الأدنى** |
| 140px | ❌ فشل |

**العرض المُختار:** ٢٢٤px على الهاتف · ٢٨٨px على الحاسوب → **ضِعف هامش الأمان**.

هذا القرار **مبنيّ على قياس لا على ذوق**.

## التشغيل والتحقّق

```bash
pip install qrcode pillow pyzbar
python3 research/scripts/qr_generate.py
```

**التحقّق من الملف:**
```bash
python3 -c "
from pyzbar.pyzbar import decode
from PIL import Image
print([d.data.decode() for d in decode(Image.open('public/images/brand/qr-keif-aldiafa.png').convert('RGB'))])
"
```

**التحقّق من المُقدَّم فعلاً — أهمّ من الأول:**
```bash
curl -s "http://localhost:3000/images/brand/qr-keif-aldiafa.png" -o /tmp/q.png
python3 -c "
from pyzbar.pyzbar import decode
from PIL import Image
im = Image.open('/tmp/q.png')
print('format:', im.format, im.size)
print([d.data.decode() for d in decode(im.convert('RGB'))] or 'FAIL')
"
```

**المعيار:** الصيغة **PNG** (لا WebP)، والفكّ يُعيد الرابط. لو ظهر `WEBP` فقد ضاع `unoptimized`.

## عند تغيير الرابط

1. عدّل `URL` في السكربت
2. شغّله
3. `rm -rf .next/cache/images && npm run build`
4. **فُكَّ المُقدَّم من الخدمة** (لا الملف وحده)
5. صوّر الصفحة وانظر إليها
6. **امسحه بهاتف حقيقي**

> ولا تحذف `unoptimized` أبداً بحجّة تحسين الأداء. هي **شرط صحّة**، ومن حذفها كسر الباركود بصمت.
