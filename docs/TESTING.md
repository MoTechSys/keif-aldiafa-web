# الاختبار والقياس

> لا يوجد في هذا المشروع اختبارات وحدة — لأن المُخرَج **بصري وتحويلي** لا منطقي. الاختبار هنا **قياسٌ للصفحة كما يراها العميل على هاتفه**.

---

## المبدأ

| النوع | الأداة |
|---|---|
| ما **يُقاس** آلياً | قِسه بسكربت — لا تنظر إليه |
| ما **لا يُقاس** | انظر إليه **بنفسك** — ولا تسأل صاحب المشروع |

القاعدة الثانية ليست مجاملة: من يطلب من صاحب المشروع أن يفحص عمله يُسلّمه عملاً غير مُختبَر.

---

## ١. قياس الصفحة على الهاتف

```bash
python3 research/scripts/shoot_mobile.py <slug-or-path> <outdir>

# أمثلة
python3 research/scripts/shoot_mobile.py sababin-qahwa-jeddah L
python3 research/scripts/shoot_mobile.py social S
```

**البيئة:** ٣٩٠×٨٤٤ @2x بمعرّف iPhone — **٩٥٪ من العملاء هنا**.
يُمرّر السكربت الصفحة كاملة أولاً (لتُحمَّل الصور المؤجّلة) ثم ينتظر فكّ الترميز ثم يُقطّع الصفحة شرائح.

### المُخرَجات وما يعنيه كل رقم

| المفتاح | المعنى | المعيار |
|---|---|---|
| `screens` | طول الصفحة بوحدة شاشة هاتف | **الأقلّ أفضل** — قاعدة الخمس ثوانٍ |
| `docW` | عرض المستند | **٣٩٠ بالضبط**؛ أكثر = تمرير أفقي = عطب |
| `broken` | صور فاشلة | **`[]` إلزاماً** |
| `price` | ظهور سعر | **`false` إلزاماً** — مبدأ «لا أسعار» |
| `wa` / `tel` | عدد نقاط الاتصال | > 0 |
| `h1txt` | العنوان الرئيسي | يُتحقَّق أنه **مختلف** بين المدن |
| `words` | عدد الكلمات | مؤشّر ثِقَل |
| `overflow` | عناصر تتجاوز حاويتها | تُفحَص |

### القياسات الحالية

| الصفحة | شاشات | `docW` | `broken` | `price` |
|---|---|---|---|---|
| `sababin-qahwa-jeddah` | ١٢٫٢ | ٣٩٠ | `[]` | `false` |
| `qahwajiin-riyadh` | ١٢٫٣ | ٣٩٠ | `[]` | `false` |
| `diyafa-munasabat-makkah` | ١٢٫٤ | ٣٩٠ | `[]` | `false` |
| `/social` | ٤٫٩ | ٣٩٠ | `[]` | `false` |

### تجاوزات حميدة معروفة (لا تُصلَح)

```
sr-only … 183>1          ← رابط تجاوز مخفي، سلوك متوقّع
relative 64>60           ← فرق تقريب
lx-medal shrink-0 47>42  ← الأيقونة تتجاوز حاويتها بالتصميم
ls-hero 415>390          ← الغلاف يمتدّ خارج الحافّة بالتصميم
```

**من رآها في المُخرَج فليتجاهلها.** أي تجاوز *آخر* يُفحَص.

## ٢. النظر بالعين — إلزامي بعد كل تغيير بصري

القياس لا يرى **الجمال ولا التصادم ولا الصورة المكسورة**. فبعد كل تصوير:

```
اقرأ الشرائح: <outdir>/s01.png · s02.png · …
```

**هذا ما وجد عطبَي `/social`:** الباركود المكسور، والسطر الملتصق بشريط الشعار. **لم يكشفهما أي رقم.**

**قائمة الفحص البصري:**
- [ ] هل شيء يتصادم مع شريط الشعار الثابت (~٩٦px)؟
- [ ] هل كل صورة تُرسَم؟ (لا أيقونة مكسورة)
- [ ] هل الصور **دافئة** لا باردة؟
- [ ] هل الأحجام منتظمة؟
- [ ] هل العنوان يُقرأ فوق الغلاف؟
- [ ] هل العلامة المائية ظاهرة بلا إزعاج؟
- [ ] **كن العميل: ونزّل لآخر الصفحة — هل تتصل فوراً؟**

## ٤. فحص حرارة اللون من البكسل

القاعدة في CSS لا تُثبت وصولها للمتصفّح. فتُقاس البكسلات من **الصورة الملتقطة**:

```python
from PIL import Image
im = Image.open('L/s08.png').convert('RGB').crop(box)
px = list(im.getdata())
R = sum(p[0] for p in px)/len(px)
B = sum(p[2] for p in px)/len(px)
print('B-R =', B-R)      # سالب = دافئ ✅ · موجب = بارد ❌
```

**القيم الحالية:** معرض يسار `−12.9` · معرض يمين `−32.9` → دافئتان.

## ٥. فحص الباركود

```bash
# الملف
python3 -c "
from pyzbar.pyzbar import decode; from PIL import Image
print([d.data.decode() for d in decode(Image.open('public/images/brand/qr-keif-aldiafa.png').convert('RGB'))])"

# المُقدَّم فعلاً — أهمّ
curl -s "http://localhost:3000/images/brand/qr-keif-aldiafa.png" -o /tmp/q.png
python3 -c "
from pyzbar.pyzbar import decode; from PIL import Image
im=Image.open('/tmp/q.png'); print(im.format, im.size)
print([d.data.decode() for d in decode(im.convert('RGB'))] or 'FAIL')"
```

**المعيار:** صيغة **PNG** والفكّ يُعيد الرابط. تفصيل: [QR-BARCODE.md](QR-BARCODE.md).
