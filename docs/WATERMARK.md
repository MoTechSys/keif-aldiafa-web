## الهدف

علامة على كل صورة تمنع السرقة، **ولا تُفسد الصورة** — لأن الصور هي دليل الجودة، ومن يُفسدها يهدم سبب وجودها.

---

## قياس الشعار — أساس التصميم كلّه

قِست `public/brand/logo-official.png` (1024×1024) بـ `numpy`:

```
قناة الشفافية (Alpha)
  ٨٠٦٣١١ بكسل عند صفر        ← خارج البيضة
  ٢٣٣٨١٥ بكسل فوق ٢٢٤        ← داخل البيضة
  → شبه ثنائية: تحمل الصورة الظاهرية للبيضة لا تفاصيلها

الإضاءة داخل الجسم (Luminance)
  أدنى ٣٥٫٦ · وسيط ١٢٧٫٣ · أعلى ١٧٦٫٨
  انحراف معياري ٦٧٫٧
  ٤٧٫١٪ من الجسم تحت L=80
  → حبر كحلي عند L≈36 على بيضة رملية عند L≈177

متوسّط اللون المعتم: RGB [124.1, 102.8, 97.1]
```

**التركيب المُستنتَج:** حبر كحلي على بيضة رملية + كلمة «كيف الضيافة» بالكحلي.

### الاستنتاج الحاسم

> التفاصيل — الشماغ، الوجه، الدلّة، الفنجان — **تعيش في تضاد اللون لا في الشفافية**.
> فأيّ صبغٍ بلون واحد يُلغي تضاد اللون، **فيمحو التفاصيل حتماً**.

هذا هو ما أسقط الإصدار ٤: لم تكن قيمته خاطئة، بل **فرضيّته**. ولا قيمة شفافية كانت لتُنجيه.

## تاريخ الإصدارات

| # | الطريقة | النتيجة |
|---|---|---|
| ١ | لصق الشعار كما هو | ثقيل، يُفسد الصورة |
| ٢ | تصغير + تخفيف | يذوب على الخلفيات الفاتحة |

| **٥** | **نقشٌ محفور (`engrave`)** | ✅ خطوط ذهبية والمحتوى يُرى من خلالها |

## الإصدار ٥ — التحويل

**الفكرة:** لا نلصق جسماً، بل **نحفر نقشاً**. نُعيد بناء الشفافية من **دكانة الحبر**.

```python
INK_L, BG_L = 40.0, 172.0        # مقاستان من الملف لا مُخمَّنتان
GOLD = (0xD8, 0xA8, 0x77)        # ذهب الصفحة

def engrave(img, rgb=GOLD):
    """يحوّل الشعار إلى نقش: الشفافية الجديدة = دكانة الحبر."""
    span = BG_L - INK_L
    for each pixel (R,G,B,A):
        if A == 0: continue
        L = 0.299*R + 0.587*G + 0.114*B
        t = (BG_L - L) / span
        if t <= 0: continue                 # أفتح من الخلفية → شفاف تماماً
        t = min(t, 1.0)
        out = rgb + (int(A * t**0.88),)     # 0.88 يُسمّن الخطوط الرقيقة
```

| المُدخَل | `t` | النتيجة |
|---|---|---|
| حبر كحلي `L≈36` | ≈ ١ | ذهب معتم — **خطّ ظاهر** |
| بيضة رملية `L≈177` | ≤ ٠ | **شفاف تماماً — نافذة** |
| رمادي متوسّط | بينهما | ذهب نصف شفاف — تدريج |

**الأثر:** العلامة **تُؤطّر الصورة ولا تغطّيها**. الكرواسان يُرى من خلال البيضة.

**لماذا `0.88` لا `1.0`؟** الأسّ أقلّ من واحد يرفع القيم المتوسّطة، فيُسمّن الخطوط الرقيقة قليلاً لتصمد بعد التصغير إلى ١٦٪ من عرض الصورة. بـ `1.0` تختفي أرقّ الخطوط عند التصغير.

## الهالة المضادّة

العلامة توضع على صور مجهولة الخلفية. فتُقاس إضاءة المنطقة تحتها وتُختار هالة **معاكسة**:

```python
halo_rgb = (0,0,0) if mean >= 128 else (0xFF,0xF4,0xE2)
```
ثم `MaxFilter` + `GaussianBlur` وشدّة `v * 1.45 * 0.62`.

فالعلامة مقروءة على الفاتح والداكن دون ضبط يدوي لكل صورة.

## الإعدادات

```python
frac    = 0.16     # عرض العلامة = ١٦٪ من عرض الصورة
opacity = 0.72
pad     = 0.042    # هامش من الحافّة
الموضع  = أسفل يمين
الحفظ   = WebP · quality=86 · method=6
```

**ملاحظة:** العلامة تبدو **باهتة عند عرض ١٧٦px** في بطاقة الهاتف — وهذا **صحيح ومقصود**. وظيفتها الحماية عند سرقة **الملف الكامل**، لا الظهور في المصغّرات. الفخامة تقتضي أن تُرى العلامة ولا تُزعج.
