# البحث والقياس

أدوات القياس التي بُنيت عليها قرارات التصميم، والأدلّة البصرية التي أثبتت الأعطاب.

> **لماذا تُحفَظ هذه في المستودع؟**
> لأن قرارات مثل «عرض الباركود ٢٢٤px» و«`INK_L = 40`» تبدو **تعسّفية** بلا الأداة التي قاستها. من يعود للمشروع ويرى رقماً بلا سبب سيغيّره — فيكسر ما لا يعرف أنه مُقاس.

## القياسات المرجعية

**الشعار** `public/brand/logo-official.png` (1024×1024):
```
الشفافية : ٨٠٦٣١١ بكسل عند صفر · ٢٣٣٨١٥ فوق ٢٢٤  → شبه ثنائية
الإضاءة  : انحراف ٦٧٫٧ · أدنى ٣٥٫٦ · وسيط ١٢٧٫٣ · أعلى ١٧٦٫٨
           ٤٧٫١٪ تحت L=80  → حبر L≈36 على رمليّ L≈177
```
→ التفاصيل في **تضاد اللون** لا الشفافية → صبغ بلون واحد يمحوها حتماً.
→ `INK_L = 40` و`BG_L = 172` **مقيستان من هنا**. إن تغيّر الشعار، أعِد القياس.

**الباركود** — فكّ `pyzbar` بحسب المقاس:
```
984 ✅ · 512 ✅ · 320 ✅ · 240 ✅ · 180 ✅ (الحدّ الأدنى) · 140 ❌
```
→ العرض ٢٢٤/٢٨٨px = **ضِعف هامش الأمان**.

**حرارة اللون** من الصورة الملتقطة (`B − R`):
```
معرض يسار −12.9 · معرض يمين −32.9    → سالب = دافئ ✅
```

**طول الصفحات** (٣٩٠×٨٤٤):
```
jeddah 12.2 · riyadh 12.3 · makkah 12.4 · /social 4.9
```
